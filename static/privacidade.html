Aviso sobre tratamento de dados (LGPD)

Ao usar o Cliora durante esta fase de testes, você concorda com o seguinte:

Dados coletados

O conteúdo do documento PDF que você envia, o ano e tipo informados e o código de convite utilizado (usado só para controle de uso diário durante o beta).

Como os dados são usados

O conteúdo do documento passa por reconhecimento de texto (OCR) e por uma etapa de correção automática assistida por inteligência artificial, antes de o resultado ser disponibilizado para download.

Armazenamento

Durante esta fase de testes, os documentos enviados e os resultados gerados ficam armazenados no servidor por prazo indeterminado. Uma política de retenção definitiva será estabelecida antes do lançamento público.

Responsabilidade do usuário

Você é responsável por garantir que tem base legal para enviar o documento, especialmente se ele contiver dados pessoais de terceiros (nomes de partes em processos judiciais, por exemplo). Evite enviar documentos com dados sensíveis de terceiros sem autorização.

Seus direitos

Você pode solicitar a exclusão dos seus dados e dos documentos enviados a qualquer momento, escrevendo para felipeabal@upf.br.

Responsável pelo tratamento

Felipe Cittolin Abal, pesquisador independente.
